# CogniPilot Workspace

Backup of the CogniPilot workspace including Cranium ROS 2 packages, custom algorithms, and tools for NXP Cup India.

## Sub-components
- `cranium/src`: ROS 2 packages (`b3rb_ros_line_follower`, `corti`, `dream_world`, `synapse_*`, `cerebri_bringup`, etc.)
- `electrode`: Ground control & telemetry interface
- `helmet`: Companion computer setup and scripts
- `installer`: CogniPilot setup scripts
- `tools`: Development tools and utilities
